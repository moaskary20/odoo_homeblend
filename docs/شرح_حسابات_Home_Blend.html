شرح كامل ومفصّل لكل ميزات الحسابات

هذا الدليل يغطي قائمة Home Blend → الحسابات بالكامل: الشجرة، التهيئة، القيود، المدفوعات، القوائم المالية، التنبؤ بالرصيد، وتسوية المدفوعات — مع خطوات تنفيذ عملية لكل ميزة.

الدخول: https://odoo.homeblendstore.com الشركة أعلى الشاشة: Home Blend القائمة: Home Blend → الحسابات

1) الفكرة العامة

نظام الحسابات مبني على شجرة الشركة بأكواد تبدأ بـ HB. التقارير والقوائم لا تُدخل فيها أرقام يدوياً. الأرقام تأتي من: القيود المرحلة، الفواتير، مدفوعات المحاسبة، ومدفوعات نقطة البيع.

حساب في الشجرة → حركة مرحّلة (قيد / فاتورة / دفعة / POS) → تحديث التقرير أو التسوية / التنبؤ
مهم: نص «البيان» في القيد للتوضيح فقط. ما يحدد ظهور المبلغ في قائمة الدخل أو الميزانية هو الحساب وحقل بند القائمة المالية عليه.

3) شجرة الحسابات

الغرض

عرض كل حسابات Home Blend وتفريعاتها حسب ملفات الشركة (شجرة / ميزان / دخل / ميزانية).

طريقة الفتح

  1. Home Blend → الحسابات → الشجرة كاملة (أو فرع مثل الأصول / المصروفات).
  2. استخدم البحث بالكود أو الاسم (مثال: HB11002 أو تجهيز مقر).

4) إنشاء حساب جديد

  1. افتح الفرع المناسب (مثلاً المصروفات → مصروفات إدارية وعمومية).
  2. اضغط جديد.
  3. الاسم + كود يبدأ ببادئة المجموعة (مثل HB32…).
  4. نوع الحساب: أصل / خصم / مصروف / إيراد…
  5. عيّن بند القائمة المالية ليظهر في الدخل أو الميزانية بالمكان الصحيح.
  6. فعّل شجرة هوم بليند إن وُجد الحقل، واحفظ.
بدون بند القائمة المالية قد يظهر المبلغ ضمن «بنود غير مبوبة» في التقارير.

5) إضافة عميل أو مورد داخل الشجرة

إضافة عميل

  1. الحسابات → الأصول → إضافة عميل.
  2. اكتب الاسم (وهاتف / رقم ضريبي اختياري) أو اختر شريكاً موجوداً.
  3. اضغط إضافة إلى الشجرة.
  4. يُنشأ حساب فرعي تحت HB12010 ويُربط كحساب مدين للشريك.

إضافة مورد

  1. الحسابات → الخصوم وحقوق الملكية → إضافة مورد.
  2. أكمل البيانات ثم إضافة إلى الشجرة.
  3. يُنشأ حساب تحت HB22003 ويُربط كحساب دائن.
بعد الربط، فواتير العميل/المورد تترحّل على حسابه وتظهر في الميزان والتقارير.

7) إنشاء دفتر يومية بنكي أو نقدي

  1. الحسابات → التهيئة → دفاتر اليومية → جديد.
  2. الاسم: مثلاً بنك CIB أو خزنة المعرض.
  3. النوع: بنك أو نقد.
  4. حساب البنك/النقد: اختر من الشجرة مثل HB12005.
  5. الشركة: Home Blend → احفظ.
إنشاء دفتر جديد لا يربطه تلقائياً بنقطة البيع. لربطه بالـ POS راجع القسم 17.

8) القيود اليومية (إدخال الأرقام)

المسار: الحسابات → القوائم → القيود اليومية → جديد
أو: الحسابات → العمليات → القيود اليومية

  1. حدد تاريخ المحاسبة ودفتر اليومية (بنك / نقد / عمليات متنوعة).
  2. افتح تبويب بنود اليومية (ليس «معلومات أخرى»).
  3. أضف سطراً: الحساب + مدين أو دائن.
  4. أضف السطر المقابل حتى يتساوى المدين مع الدائن.
  5. اضغط ترحيل. المسودة لا تدخل التقارير.

بنود القيود

من العمليات → بنود القيود ترى كل أسطر القيود للبحث والتحليل.

لوحة اليوميات

من العمليات → لوحة اليوميات لمتابعة أرصدة الدفاتر بسرعة.

9) أرصدة أول المدة / تعبئة الميزان

لا توجد شاشة إدخال ميزان سطراً بسطر. أنشئ قيداً بتاريخ قبل بداية الفترة:

طبيعة الرصيدفي القيد
مدين (أصل/مصروف)مدين على الحساب
دائن (خصم/إيراد/رأس مال)دائن على الحساب

الطرف المقابل: رأس مال / جاري شركاء / حساب افتتاحي — حسب المحاسب، مع توازن القيد ثم الترحيل.

10) المدفوعات والتحويلات

مدفوعات العملاء

  1. العمليات → مدفوعات العملاء → جديد.
  2. العميل، المبلغ، التاريخ، الدفتر (بنك/نقد)، طريقة الدفع إن ظهرت.
  3. اربط بالفاتورة إن وجدت، ثم أكّد/رحّل.

مدفوعات الموردين

  1. العمليات → مدفوعات الموردين → جديد.
  2. المورد، المبلغ، الدفتر، اربط بفاتورة المورد إن وجدت، ثم أكّد.

تحويلات نقدية

العمليات → تحويلات نقدية: لنقل مبلغ من صندوق إلى بنك أو بين حسابات سيولة دون عميل/مورد.

11) ميزان المراجعة

  1. الحسابات → القوائم → ميزان المراجعة.
  2. حدد من/إلى → تحديث.
  3. راجع: أول المدة، الحركة، آخر المدة (مدين/دائن) وحالة متوازن.
  4. اختياري: تصدير Excel أو طباعة PDF.
أول المدة = قبل تاريخ البداية · الحركة = خلال الفترة · آخر المدة = الناتج في النهاية.

12) قائمة الدخل

  1. القوائم → قائمة الدخل → حدّد الفترة → تحديث.
  2. تظهر: إيرادات النشاط، التكاليف، مجمل الربح، إيرادات أخرى، المصروفات العمومية، صافي الربح.
  3. أعلى الصفحة: نسب التكلفة والمصروفات العمومية إلى الإيراد + عمود السنة السابقة.
لتغيير رقم بند: عدّل/أضف قيداً على الحساب المناسب ثم حدّث. لا تكتب داخل القائمة نفسها.

13) الميزانية العمومية

  1. القوائم → الميزانية العمومية → تحديث.
  2. راجع الأصول المتداولة والثابتة (بالصافي بعد مخصص الإهلاك) والخصوم وحقوق الشركاء.
  3. الميزانية متوازنة عندما: الأصول = الخصوم + حقوق الشركاء.

14) تصدير Excel وطباعة PDF

على شاشات ميزان المراجعة وقائمة الدخل والميزانية:

الزرالوظيفة
تحديثإعادة الحساب من القيود المرحلة
تصدير Excelتنزيل ملف .xlsx
طباعة PDFتقرير للطباعة أو الحفظ

15) التنبؤ بالرصيد البنكي

الغرض

تقدير الرصيد اليومي المتوقع = الرصيد الحالي + وارد متوقع − صادر متوقع على أفق 30 أو 60 أو 90 يوماً.

خطوات التنفيذ

  1. العمليات → التنبؤ بالرصيد البنكي.
  2. اترك «بنك/صندوق محدد» فارغاً لإجمالي النقدية، أو اختر حساباً واحداً.
  3. اختر الأفق (30/60/90) وتاريخ البداية.
  4. فعّل: مستحقات العملاء، مستحقات الموردين، التدفقات المخططة يدوياً حسب الحاجة.
  5. اختياري: حد أدنى للتنبيه — الأيام تحته تظهر بتحذير.
  6. اضغط تحديث.
  7. راجع تبويب الرصيد اليومي وتبويب تفصيل التدفقات.

التدفقات المخططة يدوياً

  1. العمليات → تدفقات نقدية مخططة (أو زر «التدفقات المخططة» من شاشة التنبؤ).
  2. جديد: البيان، التاريخ المتوقع، وارد/صادر، المبلغ، حساب اختياري، الحالة مخطط.
  3. ارجع للتنبؤ واضغط تحديث ليدخل في الحساب.
المستحقات تُؤخذ من فواتير العملاء/الموردين المرحلة وغير المسددة بالكامل حسب تاريخ الاستحقاق.

16) تسوية المدفوعات

الغرض

مطابقة ما سجّله النظام (محاسبة + POS) مع كشف واقعي: نقد معدود، تحويل بنكي، بطاقة، محفظة.

أ) إدخال سطور الكشف

  1. العمليات → سطور كشف التسوية.
  2. أضف سطراً: التاريخ، البيان، المبلغ، وارد/صادر، الوسيلة (نقدي/تحويل/بطاقة/محفظة)، المرجع إن وُجد.
  3. الحالة الافتراضية: غير مسوّى.

ب) تشغيل التسوية

  1. العمليات → تسوية المدفوعات.
  2. حدد من/إلى، الوسيلة (أو الكل)، ودفتر اختياري.
  3. فعّل مدفوعات المحاسبة و/أو نقطة البيع.
  4. اضغط تحديث — يظهر إجمالي النظام والكشف والفرق وعدد غير المسوّى.
  5. مطابقة تلقائية: نفس المبلغ والاتجاه، فرق تاريخ ≤ 3 أيام، مع تفضيل تطابق المرجع.
  6. أو علّم اختيار على سطر نظام + سطر كشف ثم مطابقة المحدد (يجب تساوي المبلغ).
  7. لإلغاء مطابقة: من سطور الكشف → إلغاء المطابقة.
السطر المسوّى يُربَط بدفعة محاسبة أو دفعة POS ويُستبعد من غير المسوّى في التحديثات التالية.

17) الربط مع نقطة البيع

  1. أنشئ دفتر بنك/نقد من التهيئة واربطه بحساب HB.
  2. افتح إعداد نقطة البيع (المبيعات → نقطة البيع).
  3. في طرق الدفع: اربط النقد/البطاقة/التحويل بالدفتر المناسب.
  4. احفظ وافتح جلسة جديدة حتى يسري الربط.
دفتر جديد من التهيئة لا يذهب تلقائياً للـ POS دون ربط طريقة الدفع.

19) قائمة تحقق يومية للمحاسب

  • الشركة النشطة: Home Blend.
  • الحساب عليه بند القائمة المالية الصحيح.
  • القيود والمدفوعات مرحّلة/مؤكدة وليست مسودة.
  • تاريخ الحركة داخل فترة التقرير.
  • بعد التحديث: الميزان/الميزانية متوازنان إن انطبق.
  • الكشف اليومي مُدخل في سطور التسوية ومطابق قدر الإمكان.
  • التدفقات المخططة الكبيرة (رواتب/إيجار) مسجّلة للتنبؤ.

20) أسئلة شائعة

قائمة الدخل أصفار؟
لا توجد قيود/فواتير مرحّلة على حسابات الإيراد والمصروف في الفترة.
هل البيان يجب أن يطابق اسم بند القائمة؟
لا. المهم الحساب الصحيح.
لا أجد دفاتر اليومية؟
هي داخل Home Blend الآن: الحسابات → التهيئة → دفاتر اليومية. حدّث الصفحة Ctrl+F5.
دفتر البنك لا يظهر في الـ POS؟
اربطه من إعداد نقطة البيع → طرق الدفع، ثم جلسة جديدة.
لا يظهر تبويب بنود اليومية في القيد؟
تحتاج صلاحيات محاسبة. حساب المدير يفترض أنه مفعّل؛ وإلا من الإعدادات → المستخدمون.
التقارير تحت Home Blend → التقارير؟
تقارير مستأجرين ومبيعات إضافية هناك. القوائم الرسمية للشجرة تحت الحسابات → القوائم.
