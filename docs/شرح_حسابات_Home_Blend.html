مقدمة سريعة

الأرقام لا تُكتب داخل التقارير. تأتي من القيود المرحلة، الفواتير، مدفوعات المحاسبة، ومدفوعات نقطة البيع. ما يحدد ظهور المبلغ في قائمة الدخل أو الميزانية هو الحساب وحقل بند القائمة المالية — وليس نص «البيان» في القيد.

حساب في الشجرة → حركة مرحّلة → تحديث التقرير / التسوية / التنبؤ

1) الشجرة كاملة

الغرض: عرض كل حسابات Home Blend بأكواد HB… دفعة واحدة.

  1. Home Blend → الحسابات → الشجرة كاملة.
  2. ابحث بالكود أو الاسم (مثال: HB11002 أو تجهيز مقر).
  3. افتح الحساب لمراجعة النوع وبند القائمة المالية.
الكودالمجموعةأمثلة
HB1 / HB11–13الأصولتجهيز مقر، بنوك، عملاء، مخزون
HB2 / HB21–23الخصوم وحقوق الملكيةرأس المال، موردون، مخصص إهلاك
HB3 / HB31–32المصروفاتتكاليف عمليات، إيجارات، رواتب
HB4 / HB41–44الإيراداتمبيعات، إيجار، فوائد بنكية

إنشاء حساب جديد من أي فرع

  1. افتح الفرع المناسب → جديد.
  2. الاسم + كود يبدأ ببادئة المجموعة (مثل HB32…).
  3. نوع الحساب + بند القائمة المالية → احفظ.
بدون بند القائمة المالية قد يظهر المبلغ ضمن «بنود غير مبوبة» في التقارير.

6) العمليات

هنا العمل اليومي: إدخال القيود والمدفوعات والتنبؤ والتسوية. نفّذ هنا أولاً ثم افتح القوائم.

6.1 لوحة اليوميات

عرض بطاقات دفاتر البنك/النقد/المبيعات لمتابعة الأرصدة بسرعة والدخول لإنشاء قيد من الدفتر.

  1. الحسابات → العمليات → لوحة اليوميات.
  2. اختر الدفتر المطلوب لفتح حركاته أو إنشاء قيد جديد.

6.2 القيود اليومية

هذه شاشة إدخال الأرقام الأساسية (أرصدة افتتاحية، مصروف نقدي، أصل ثابت…).

  1. العمليات → القيود اليومية → جديد.
  2. التاريخ + دفتر اليومية (بنك / نقد / عمليات متنوعة).
  3. تبويب بنود اليومية: سطر مدين + سطر دائن حتى يتساويا.
  4. اضغط ترحيل — المسودة لا تدخل التقارير.

أرصدة أول المدة

أنشئ قيداً بتاريخ قبل بداية الفترة: مدين للأصول، دائن للخصوم/رأس المال، ثم رحّل.

6.3 بنود القيود

كل أسطر القيود المرحلة والمسوّدة في قائمة واحدة للبحث والفلترة (حسب حساب، تاريخ، شريك).

6.4 مدفوعات العملاء

  1. العمليات → مدفوعات العملاء → جديد (أو Home Blend → التحصيل).
  2. العميل، المبلغ، التاريخ.
  3. اختر اليومية: الخزينة الرئيسية للنقد أو البنك – الحساب الرئيسي للتحويل/البطاقة/أخرى.
  4. اربط بالفاتورة → أكّد / رحّل → اطبع إيصال التحصيل.

القيد: مدين HB12001 أو HB12005 ← دائن العملاء HB12010.

6.5 مدفوعات الموردين

  1. العمليات → مدفوعات الموردين → جديد (أو المشتريات → مدفوعات الموردين).
  2. المورد، المبلغ، اختر الخزينة أو البنك الرئيسي، اربط بفاتورة المورد → أكّد.

القيد: مدين الموردون HB22003 ← دائن الخزينة أو البنك.

6.6 تحويلات نقدية

نقل مبلغ من صندوق إلى بنك أو بين حسابات سيولة دون عميل/مورد.

6.7 التنبؤ بالرصيد البنكي

تقدير يومي: الرصيد الحالي + وارد متوقع − صادر متوقع على أفق 30/60/90 يوماً.

  1. العمليات → التنبؤ بالرصيد البنكي.
  2. اترك الحساب فارغاً لإجمالي النقدية أو اختر بنكاً/صندوقاً.
  3. فعّل مستحقات العملاء / الموردين / التدفقات المخططة حسب الحاجة.
  4. تحديث ثم راجع الرصيد اليومي وتفصيل التدفقات.
  5. تصدير Excel أو طباعة PDF من أعلى الشاشة.

6.8 تدفقات نقدية مخططة

  1. العمليات → تدفقات نقدية مخططة (أو زر من شاشة التنبؤ).
  2. جديد: البيان، التاريخ، وارد/صادر، المبلغ، الحالة مخطط.
  3. ارجع للتنبؤ واضغط تحديث.

6.9 تسوية المدفوعات

مطابقة ما سجّله النظام (محاسبة + POS) مع كشف واقعي: نقد، تحويل، بطاقة، محفظة.

  1. أدخل أولاً سطور الكشف (القسم التالي).
  2. العمليات → تسوية المدفوعات → من/إلى → تحديث.
  3. مطابقة تلقائية أو علّم سطر نظام + سطر كشف ثم مطابقة المحدد.
  4. راجع الفرق وعدد غير المسوّى، ثم Excel / PDF.

6.10 سطور كشف التسوية

  1. العمليات → سطور كشف التسوية.
  2. أضف: التاريخ، البيان، المبلغ، وارد/صادر، الوسيلة، المرجع.
  3. الحالة: غير مسوّى حتى تتم المطابقة من شاشة التسوية.
  4. للتصدير: حدّد السطور → إجراء → تصدير Excel أو طباعة PDF.

7) القوائم

تقارير رسمية مبنية على شجرة Home Blend. بعد أي قيد جديد اضغط تحديث.

أسطورة الألوان الموحّدة لكل التقارير المالية (الشاشة + PDF + Excel): أزرق فاتح = عنوان قسم · كهرماني = إجمالي · أخضر = نتيجة ≥ 0 · أحمر صف = نتيجة/تنبيه < 0 · أخضر مزرق = مدين / وارد / مخطط / تكلفة · بنفسجي = دائن / صادر / انحراف / إهلاك · أحمر رقم = قيمة سالبة (−). تشمل: ميزان المراجعة، قائمة الدخل، الميزانية، القائمة الرسمية، تفصيل الإيراد/المصروف، الذمم، التدفقات، الضرائب، التنبؤ النقدي، التسوية، الميزانية التقديرية، والأصول. الأسهم ⟸ توضّح اتجاه الإجمالي والنتيجة (RTL).

7.1 ميزان المراجعة

  1. القوائم → ميزان المراجعة → من/إلى → تحديث.
  2. راجع أول المدة / الحركة / آخر المدة وحالة متوازن.
  3. صف الإجمالي يُلوَّن كنتيجة عند التوازن، وكإجمالي عند عدم التوازن.
  4. تصدير Excel أو طباعة PDF بنفس الألوان.

7.2 قائمة الدخل

  1. القوائم → قائمة الدخل → الفترة → تحديث.
  2. إيرادات النشاط، التكاليف، مجمل الربح، إيرادات أخرى، المصروفات العمومية، صافي الربح.
  3. سطور «مجمل…» و«صافي أرباح أو خسائر العام» ملوّنة كنتيجة (أخضر/أحمر) مع سهم ⟸.
  4. تظهر نسب التكلفة والمصروفات + عمود السنة السابقة.
لتغيير رقم بند: عدّل القيد على الحساب ثم حدّث — لا تكتب داخل القائمة.

7.3 الميزانية العمومية

  1. القوائم → الميزانية العمومية → تحديث.
  2. الأصول (بالصافي بعد مخصص الإهلاك) = الخصوم + حقوق الشركاء عند التوازن.
  3. «صافي أرباح أو خسائر العام» يظهر كنتيجة ملوّنة؛ المجاميع بخلفية كهرمانية.

7.4 قائمة مالية رسمية

معالج سريع: اختر ميزانية أو أرباح وخسائر + الفترة → تصدير Excel أو طباعة PDF (عرض مبسّط حسب أنواع حسابات Odoo).

8) تقارير مالية

تقارير تفصيلية إضافية (ليست بديلاً عن القوائم الرسمية أعلاه). كلها تدعم تحديث + Excel + PDF.

8.1 تفصيل الإيرادات

أسطر القيود على حسابات الإيراد خلال الفترة.

8.2 تفصيل المصروفات

أسطر القيود على حسابات المصروف خلال الفترة.

8.3 التدفقات النقدية

حركات حسابات النقدية والبنوك (asset_cash) خلال الفترة.

8.4 تقرير الضرائب

أسطر القيود المرتبطة ببنود ضريبية.

8.5 الذمم المدينة

فواتير العملاء المرحلة غير المسددة / الجزئية في الفترة.

8.6 الذمم الدائنة

فواتير الموردين المرحلة غير المسددة / الجزئية.

8.7 الميزانية التقديرية

  1. جديد: اسم الميزانية + من/إلى.
  2. أضف بنوداً: حساب + مبلغ مخطط (+ مركز تكلفة اختياري).
  3. النظام يحسب الفعلي والانحراف من القيود المرحلة.
  4. اعتماد → ثم Excel / PDF.

8.8 الأصول والإهلاك

  1. سجّل الأصل: التكلفة، الخردة، سنوات الإهلاك.
  2. بدء الإهلاك → ترحيل قيد الإهلاك الشهري عند الحاجة.
  3. تصدير القائمة Excel / PDF من الشاشة أو إجراء القائمة.

9) التهيئة

إعداد لمرة واحدة أو عند إضافة بنك/ضريبة جديدة. يُفضّل ضبطها قبل بدء العمليات اليومية.

9.1 دفاتر اليومية

اليوميات الجاهزة لـ Home Blend (تُنشأ/تُحدَّث تلقائياً مع الترقية):

الكودالاسمالنوعالحسابالاستخدام
HBCSH الخزينة الرئيسية نقد HB12001 صندوق المكتب الرئيسي تحصيل نقدي / سداد مورد نقداً — طريقة دفع: نقدي
HBBNK البنك – الحساب الرئيسي بنك HB12005 البنك التجاري الدولي تحويل بنكي، بطاقة بنكية، وسائل دفع أخرى (قبض وصرف)
STJ قيود المخزون عام مرتبط بتقييم المخزون قيود التكلفة/المخزون الآلية (Anglo-Saxon)
  1. التهيئة → دفاتر اليومية — راجع HBCSH و HBBNK أولاً قبل إنشاء دفاتر إضافية.
  2. لإضافة دفتر فرعي (معرض/خزنة): جديد → نوع بنك أو نقد → اربط حساب HB المناسب → الشركة Home Blend.
  3. طرق الدفع على الدفتر: نقدي على الخزينة؛ تحويل/بطاقة/أخرى على البنك.
إنشاء دفتر إضافي لا يربطه تلقائياً بنقطة البيع — راجع قسم POS لربط طرق الدفع.
للاستخدام اليومي في التحصيل والسداد: اختر دائماً الخزينة الرئيسية أو البنك – الحساب الرئيسي حتى تطابق القيود حسابات الشجرة HB.

9.2 الحسابات البنكية

أرقام IBAN/حسابات على الشركاء والشركة لاستخدامها في المدفوعات والمراسلات. الحساب المحاسبي للتحصيل البنكي الرئيسي هو HB12005 عبر يومية HBBNK.

9.3 دليل الحسابات

كل حسابات Odoo للشركة (أوسع من فلتر شجرة HB). مفيد للبحث الشامل أو الحسابات الافتراضية للنظام.

9.4 الضرائب

تعريف ضريبة القيمة المضافة وغيرها قبل الفوترة الخاضعة للضريبة.

9.5 شروط الدفع

آجل / أقساط — تُربط بالعقود والبيع.

9.6 الأوضاع المالية

خرائط ضريبية حسب نوع الشريك أو الدولة.

9.7 مراكز التكلفة

يظهر إن فُعّلت المحاسبة التحليلية — للتحليل حسب مشروع أو فرع.

دورة البيع والمخزون السالب

يمكن إتمام البيع والتسليم برصيد صفر فيصبح المخزون سالباً، ثم تغطيته بالشراء والاستلام. التقييم دائم (عند الفوترة) مع Anglo-Saxon ومتوسط مرجح.

  1. بيع كمية غير متوفرة → تسليم → رصيد سالب.
  2. ترحيل فاتورة العميل:
    عملاء HB12010 ← إيراد HB42001
    تكلفة HB31000 ← مخزون HB12012 (تلقائي)
  3. شراء واستلام نفس الكمية → الرصيد يعود لصفر بدون خصم مزدوج.
  4. فاتورة المورد: مخزون ← موردون HB22003. فرق السعر على HB31019.

التحصيل وسداد المورد والربح

  1. تحصيل نقدي: يومية HBCSH / HB12001 ← عملاء HB12010 + إيصال تحصيل مربوط بالفاتورة.
  2. تحصيل بنكي/بطاقة/أخرى: يومية HBBNK / HB12005 ← عملاء.
  3. سداد مورد: موردون HB22003 ← خزينة أو بنك.
  4. مجمل الربح: المبيعات − تكلفة البضاعة في قائمة الدخل — يخص Home Blend. تحمل 80/20 توزيع مسؤولية فاتورة وليس مشاركة أرباح.

قائمة تحقق يومية

  • الشركة النشطة: Home Blend.
  • التحصيل/السداد على HBCSH أو HBBNK.
  • الحساب عليه بند القائمة المالية الصحيح.
  • القيود والمدفوعات مرحّلة.
  • تكلفة الأصناف مضبوطة حتى يظهر قيد HB31000.
  • تاريخ الحركة داخل فترة التقرير.
  • بعد التحديث: الميزان/الميزانية متوازنان.
  • سطور الكشف مُدخلة ومطابقة قدر الإمكان.
  • التدفقات الكبيرة (رواتب/إيجار) مسجّلة للتنبؤ.

قائمة الدخل أصفار؟
لا توجد قيود/فواتير مرحّلة على حسابات الإيراد والمصروف في الفترة.
هل البيان يجب أن يطابق اسم بند القائمة؟
لا. المهم الحساب الصحيح.
أين دفاتر اليومية؟
الحسابات → التهيئة → دفاتر اليومية. استخدم HBCSH و HBBNK. حدّث الصفحة Ctrl+F5.
دفتر البنك لا يظهر في الـ POS؟
اربط HBBNK/HBCSH من إعداد نقطة البيع → طرق الدفع، ثم جلسة جديدة.
لماذا لا تظهر تكلفة البضاعة؟
ضع تكلفة الصنف، وتأكد أن الفئة بتقييم دائم وحساب HB31000.
ماذا يفعل المرتجع محاسبياً؟
يعكس الإيراد ودين العميل، ويعكس التكلفة/المخزون تلقائياً للمنتج المخزني.
لا يظهر تبويب بنود اليومية؟
صلاحيات محاسبة ناقصة — من الإعدادات → المستخدمون.
فرق القوائم عن تقارير مالية؟
