تدريب عملي: دورة Home Blend المحاسبية

نفّذ التمارين بالترتيب على شركة Home Blend. كل تمرين يذكر اسم الصفحة في النظام + ماذا يُسجَّل + القيد المحاسبي المتوقع. المصدر: ملف HOME BLEND auto ledger accounts.

شركة العمل: Home Blend مثال: بيع 100,000 · تكلفة 70,000 · ربح 30,000 تحمل فاتورة 80/20 ≠ مشاركة أرباح

مقدمة التمرين

عميل + صنف → بيع (حتى لو المخزون صفر) → مخزون سالب + إيراد + تكلفة → شراء واستلام → تحصيل عميل → سداد مورد → قراءة مجمل الربح
قبل البدء: تأكد أنك على شركة Home Blend وليست Art Casa. بعد أي تحديث واجهة حدّث الصفحة بـ Ctrl+F5.

تمرين 1 — تسجيل العملاء وتحمل 80/20

الهدف: إنشاء عميل شركة مع تحمل فاتورة (ليست أرباحاً).

الصفحات

Home Blend → الحسابات → الأصول → العملاء / إضافة عميل
أو بطاقة الشريك من جهات الاتصال، ثم تفعيل تقسيم التحمل من بطاقة الشركة حسب الدليل.

  1. أنشئ عميل شركة.
  2. أضف أفراداً تابعين إن لزم.
  3. اضبط نسبة التحمل مثال: الشركة 80٪ = 80,000 · Home Blend 20٪ = 20,000.
الطرفنسبة التحملالمبلغ
الشركة80%80,000
Home Blend20%20,000
الإجمالي100%100,000
نسبة 80/20 توزيع مسؤولية قيمة الفاتورة فقط — وليست مشاركة في الأرباح.
تحقق: بطاقة العميل تظهر في العملاء، والنسب محفوظة قبل البيع.

تمرين 2 — تعريف الأصناف

الهدف: صنف مخزني جاهز للبيع والشراء مع باركود.

الصفحات

Home Blend → المبيعات → المنتجات
Home Blend → المبيعات → فئات المنتجات
Home Blend → المبيعات → توليد باركودات المنتجات

  1. أنشئ صنفاً مخزنياً: كود، اسم، مجموعة، سعر شراء، سعر بيع، مورد.
  2. تأكد من حسابات الفئة: مخزون / مبيعات / تكلفة مبيعات.
  3. ضع تكلفة تقديرية تناسب مثال 70,000 لعشر قطع (7,000 للقطعة) أو أرقام تناسب تمرينك.
  4. أنشئ/اطبع الباركود أو QR.
تحقق: المنتج يظهر في نقطة البيع ويمكن مسح باركوده.

تمرين 3 — دورة إنشاء طلب البيع / نقطة البيع

الهدف: بيع 10 قطع والسعر الإجمالي 100,000.

الخيار أ — أمر بيع

Home Blend → المبيعات → أوامر البيع

  1. جديد → اختر العميل.
  2. امسح QR/باركود الصنف أو اكتب الكود ثم أضف.
  3. الكمية 10 → تأكيد الأمر → إنشاء فاتورة العميل → ترحيل.

الخيار ب — نقطة البيع (الأشهر للكاشير)

Home Blend → المبيعات → نقطة البيع
Home Blend → المبيعات → طلبات نقطة البيع

  1. افتح جلسة POS.
  2. اختر العميل (+ العقد إن لزم).
  3. امسح باركود الصنف → كمية 10.
  4. ادفع نقداً أو آجل حسب التمرين.
  5. راجع الطلب في طلبات نقطة البيع والفاتورة في فواتير العملاء.
تحقق: المبيعات → فواتير العملاء تظهر فاتورة مرحّلة بمبلغ ≈ 100,000.

تمرين 5 — دورة الشراء بعد البيع

الهدف: تغطية الرصيد السالب (−10) بشراء واستلام +10.

الصفحات بالترتيب

  1. المشتريات → معاملات الموردين → الموردون — تأكد المورد.
  2. المشتريات → أوامر الشراء → أوامر الشراء — أمر بكمية 10.
  3. من أمر الشراء نفّذ استلام الأصناف حتى الحالة Done.
  4. المبيعات → المنتجات — الرصيد النهائي يصبح 0.
  5. المشتريات → معاملات الموردين → فواتير الموردين — رحّل فاتورة ≈ 70,000.

تمرين 6 — دورة تحصيل العميل

الهدف: تحصيل 100,000 وربط الإيصال بالفاتورة.

الصفحة

Home Blend → التحصيل → مدفوعات العملاء / إيصالات التحصيل
أو الحسابات → العمليات → مدفوعات العملاء

  1. جديد → العميل → المبلغ 100,000.
  2. اختر اليومية:
    • نقدي: الخزينة الرئيسية HBCSH / HB12001
    • تحويل/بطاقة: البنك – الحساب الرئيسي HBBNK / HB12005
  3. اربط الدفعة بفاتورة العميل → أكّد.
  4. اطبع إيصال التحصيل من الدفعة.

تمرين 8 — حساب الأرباح (مجمل الربح)

الهدف: قراءة أن كامل مجمل الربح يخص Home Blend.

البيانالمبلغ
إجمالي المبيعات100,000
تكلفة البضاعة المباعة70,000
مجمل الربح30,000

الصفحة

Home Blend → الحسابات → القوائم → قائمة الدخل → من/إلى → تحديث

  1. راجع إيراد المبيعات وتكلفة البضاعة وصافي/مجمل الفترة.
  2. اختياري: ميزان المراجعة و الميزانية العمومية.
لا توجد مشاركة في صافي الأرباح من نسبة 80/20. عمولة المستأجر — إن وُجد عقد — فاتورة منفصلة وليست اقتسام مجمل ربح البضاعة.

قائمة تحقق نهائية

  • عميل مسجّل + نسب تحمل (إن استخدمتها)
  • صنف مخزني بتكلفة وباركود
  • بيع POS أو أمر بيع → فاتورة عميل مرحّلة
  • كمية المنتج كانت سالبة ثم عادت لصفر بعد الاستلام
  • قيود الإيراد والتكلفة ظاهرة في القيود اليومية
  • أمر شراء + استلام + فاتورة مورد مرحّلة
  • تحصيل عميل مربوط بالفاتورة
  • سداد مورد مربوط بفاتورة المورد
  • قائمة الدخل تعرض مبيعات − تكلفة ≈ مجمل ربح التمرين
